# Pith 0.3.0：一次说完，继续修改

日期：2026-10-24。仅实现日常输入和修改的实际价值功能，不包含账号、订阅、支付、增长或商业化模块。

参考 Typeless 的[听写流程](https://www.typeless.com/help/quickstart/dictate)、[文本修改](https://www.typeless.com/help/quickstart/ask-anything)和[个性化](https://www.typeless.com/help/quickstart/personalization)。本轮使用用户明确选择的表达风格与结果编辑，不宣称实现 Typeless 的自动学习或选区语音编辑。

| 使用场景 | 实现 | 边界 |
| --- | --- | --- |
| 同一段话用于聊天、正式消息或任务列表 | 自然、简洁、正式、轻松、要点 5 种风格 | 提示词约束，表达质量依赖所配置的模型 |
| 识别后改一个名字、时间或句子 | 独立编辑窗口，保存、复制、手动插入 | 不读取其他应用的文本；仍使用录音时捕获的原输入框身份 |
| 同一段话换语言或换语气 | 选择当前文字或原始转写，直接重新整理/翻译 | 重新处理只发文字，不自动插入，避免重复回填 |
| 不满意新版本 | 恢复上一版，原文可展开查看和复制 | 仅保留一个上一版，内存中保存；不做跨重启版本历史 |
| 转写成功，模型整理失败 | 原文立即保留，后续只重试文字处理 | 语音识别本身失败时仍需重试音频；取消前尚未识别出文字的录音会删除 |
| 编辑中误按录音快捷键 | 未保存修改阻止新录音；关闭编辑器仍保留草稿 | 新录音和退出清除本次内存草稿；长期保存需开启历史 |
| API 配置或服务异常 | 按 HTTP 状态给出修复建议，不回显服务商错误正文 | 详细服务商诊断需到服务商平台查看 |

历史默认关闭。本轮兼容旧历史文件，增加可选风格字段；保存修改或成功重新处理会更新同一条记录，原始转写不会被中间译文替换。Keychain、macOS 系统语音识别和原有权限设置沿用。

后续可考虑按应用记忆风格、用户主动选区后的语音修改和历史复用；当前版本未实现这些能力。
