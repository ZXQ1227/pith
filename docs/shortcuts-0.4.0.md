# Pith 0.4.0 快捷键与触发交互

本轮只改善实际输入体验，没有新增收费、账号或商业化功能。

## 默认操作

| 操作 | 行为 |
| --- | --- |
| 轻按 Fn / 🌐 | 开始听写；再次轻按结束当前录音 |
| Fn + 左 Shift | 开始翻译；之后单按 Fn 完成 |
| Esc | 取消录音或处理；空闲时不占用 Esc |
| Control + Option + Space | 默认听写备用键；升级时保留用户原有组合 |
| Control + Option + Shift + Space | 翻译备用键 |

Fn 在松开时识别一次完整手势，无需一直按住。左 Shift 可以先按或后按，也可先松开；右 Shift 和其他修饰键组合不触发。Fn 搭配普通按键、方向键、功能键不触发录音，包括先按住普通键再按 Fn。Fn 监听期间，单独 Fn 的系统表情/输入法动作被 Pith 接管；换回组合键主快捷键即可释放 Fn。

首次升级迁移到 Fn 模式，保留原有听写组合，同时添加翻译备用组合。以后尊重用户保存的选择。Fn 需要在 macOS“隐私与安全性 → 辅助功能”允许 Pith；未授权时备用组合仍能使用。

## 设置和反馈

- 在“快捷键”设置录入额外组合，分别指定听写或翻译，最多八个。支持 Control、Option 或带其他修饰键的 Command 组合；拒绝普通输入、单独 Command 和 Esc。
- 录入时暂停 Pith 全局快捷键，避免误启动录音；Esc 放弃。重复组合不会保存，被其他应用占用的组合显示错误并停用。
- 可为组合键选择“按一下开始/结束”或“按住说话/松开结束”。Fn 始终单按切换。只有启动按住录音的那一个组合键的松开事件能结束它，其他键的松开不会误结束。
- 录音条区分“正在听写”和“语音翻译”，显示对应结束提示，始终提供结束与取消按钮。翻译时可直接修改本次目标语言，选择也保存为下次默认值。
- 休眠或切换系统会话会取消当前操作并清理按键状态；恢复后重新注册组合键。Fn 监听中断或权限丢失会清理未完成手势。
- 快捷键触发新录音时若编辑器有未保存修改，会打开编辑器提示处理，保留文字。

## 对标来源与边界

2026-10-24 查阅 Typeless 官方 [听写指南](https://www.typeless.com/help/quickstart/dictate)、[翻译指南](https://www.typeless.com/help/quickstart/translate)、[设置指南](https://www.typeless.com/help/quickstart/settings) 及 [macOS 更新记录](https://www.typeless.com/help/release-notes/macos)，对齐 Fn 单按听写、Fn + 左 Shift 翻译、Fn 结束、额外快捷键和录音时选择目标语言的核心流程。

这不代表完整复刻：Pith 保留组合键按住说话，不支持任意修饰键单键自定义；Fn 需要该键盘向 macOS 报告标准 Fn 事件，无法上报的外接键盘请使用备用组合。真实 Fn 事件、系统快捷键兼容性和跨应用粘贴还需对应权限及硬件实测。
